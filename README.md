# PicToPDF

אפליקציה פשוטה ונקייה להפיכת תמונות לקובץ PDF – עובדת באייפון ובאנדרואיד.

## מה אפשר לעשות
- **לבחור תמונות מהגלריה** (אחת או כמה ביחד) או **לצלם ישירות** במצלמה
- **לסדר מחדש** בגרירה (לחיצה ארוכה על תמונה וגרירה)
- **לסובב או למחוק** – הקשה על תמונה פותחת תצוגה מלאה
- לבחור **גודל עמוד** (A4 / Letter / לפי התמונה), **כיוון**, **שוליים** ו**איכות**
- לתת **שם לקובץ**
- **לשתף או לשמור** את ה-PDF (WhatsApp, מייל, Files, Google Drive וכו')

הכל קורה על המכשיר עצמו – התמונות לא נשלחות לשום שרת. אחרי הפתיחה הראשונה האפליקציה עובדת גם בלי אינטרנט.

## התקנה על הטלפון
האפליקציה היא PWA – מתקינים אותה ישירות מהדפדפן, בלי App Store או Google Play:

- **iPhone (Safari):** לפתוח את הקישור ← כפתור שיתוף ← "הוספה למסך הבית"
- **Android (Chrome):** לפתוח את הקישור ← תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית"

אחרי ההתקנה יש אייקון על המסך והאפליקציה נפתחת במסך מלא כמו כל אפליקציה אחרת.

## פרסום (GitHub Pages)
בכל push ל-`main` האתר מתפרסם אוטומטית דרך `.github/workflows/pages.yml`.
הפעלה חד-פעמית: ב-GitHub → **Settings → Pages → Source: GitHub Actions**.
הכתובת תהיה: `https://<username>.github.io/PicToPDF/`

## הרצה מקומית
```bash
python3 -m http.server 8000
# ולפתוח http://localhost:8000
```
(המצלמה ו-Service Worker דורשים HTTPS או localhost.)

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה המסך |
| `styles.css` | עיצוב (כולל מצב כהה ותמיכה ב-notch של אייפון) |
| `app.js` | לוגיקה: טעינת תמונות, סידור, סיבוב, יצירת PDF, שיתוף |
| `sw.js` | עבודה אופליין |
| `vendor/` | [jsPDF](https://github.com/parallax/jsPDF) ו-[SortableJS](https://github.com/SortableJS/Sortable) |

כשמשנים קבצים, מעלים את מספר הגרסה של `CACHE` ב-`sw.js` כדי שהמכשירים יקבלו את העדכון.
